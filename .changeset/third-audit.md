Third audit. Reauthentication accepts a rotated SolisCloud key: a new key ID is accepted when it still sees every plant the entry reads, and a SolisCloud-only entry's unique ID follows the key ID on reauth and reconfigure. Switching an entry's connection no longer lets two entries read the same account. A Modbus or Solarman stick with SolisCloud backup no longer creates and then deletes the cloud plant, logger and EPM devices each time the stick pauses. A logger repair opened before a reload now clears when the stick sleeps. A Modbus TCP session (S2-WL-ST, S5, gateways) stays open after one timeout and skips the late reply, because closing the socket can wedge port 502 on S2-WL-ST firmware. Solarman V5 requests use an 8-bit sequence and skip frames that are not inverter data, like pysolarmanv5. SolisCloud code 1 "Communication error" is retried and the last sample held, instead of failing the update; a code 429 in the body is a rate limit. A pending SolisCloud alarm whose end time has passed no longer keeps the Alarm sensor on. A bracketed `(UTC+10:00)` plant time zone is parsed. "Phase n power" is renamed "Grid phase n power", because SolisCloud's `pA`/`pB`/`pC` are the grid meter's phase power; entity IDs are kept. Device removal uses the 2026.8 device registry API. Adding a stick with backup on an account that already has a SolisCloud-only entry says to use Reconfigure on that entry. Data source has state icons, and several texts and docs were corrected, including the gateway port list, the timezone help, two Dutch strings, and the S5-WiFi-ST row in the connection guide. Two local-with-backup entries on one SolisCloud account no longer collide: the entry that added a plant first keeps the plant and EPM sensors, each web-page stick entry shows only its own logger, and the other entry takes the plant over when the first is removed. On Modbus TCP and RTU links, a hybrid inverter that also answers the 3000-range registers is detected as a hybrid from register 35000 (Solarman V5 sticks are not asked, because a high read locks the Solis-mini 4G). The docs no longer claim for certain that S4-WIFI-ST, S6 USB and 4G sticks have no local port.
