These files are the Solis artwork already published for this domain in
home-assistant/brands under custom_integrations/solis. icon.png and logo.png
are those files unchanged. icon@2x.png and logo@2x.png are exact 2× scales
of them, because that repository does not publish a high-DPI version.

Home Assistant 2026.3 and newer load this folder locally. Older versions
keep using the brands CDN, which serves the same icon and logo.
